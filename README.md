One original fortune for the houseplant on the windowsill:

> "On Thursday the sunbeam you saved all winter arrives — lean into it, and you will grow an inch taller by Friday."

## How it works

`main.py` writes the line above (112 characters, inside the 1–120 gate) to
`/output/entry.txt`, where the house gate and judge read it. Nothing else is
generated at run time, so the judged text is exactly the reviewed line.
